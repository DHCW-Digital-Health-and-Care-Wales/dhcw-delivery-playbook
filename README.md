## What does this repository now contain?

This repository (`DHCW-Digital-Health-and-Care-Wales/dhcw-delivery-playbook`) acts solely as a **tombstone and redirection host** for GitHub Pages:

- [index.html](index.html): Displays a "We've moved" interstitial notification and automatically redirects visitors from the old root domain to `https://gigcymru.github.io/dhcw-delivery-playbook/`.
- [404.html](404.html): Serves as GitHub Pages' catch-all for any legacy deep link (e.g. `/team-roles/`, `/service-lifecycle/`), extracting the target path and sending users directly to the matching page on the new site.

## Action Required for Users and Maintainers

### 1. Update Git Remotes
If you have an existing local clone of this repository, update your origin remote:

```bash
git remote set-url origin https://github.com/GIGCymru/dhcw-delivery-playbook.git
git fetch origin
```

### 2. Update Bookmarks and Links
Please update your bookmarks and any external documentation references to point to:  
`https://gigcymru.github.io/dhcw-delivery-playbook/`

### 3. Issues and Pull Requests
Do not open new issues or pull requests here. Please visit the [GIGCymru issues page](https://github.com/GIGCymru/dhcw-delivery-playbook/issues).
